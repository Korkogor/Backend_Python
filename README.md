# Python Coursework — MTUCI

Exercises and small projects completed as part of an elective Python course
at MTUCI (Moscow Technical University of Communications and Informatics).

This repository grows as the course progresses.

## Learning Goals

- Learn Python fundamentals.
- Practise solving programming tasks.
- Build small applications.
- Develop a habit of documenting code and using Git.


## Running the Code

Python 3 is required.

Open the directory of an exercise and run its Python file:

```bash
python <filename>.py
```

Replace `<filename>` with the actual filename.

If an exercise requires additional packages, installation instructions
are provided in its README.
